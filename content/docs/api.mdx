Every v1 endpoint is under `https://www.vestiarion.xyz/api/v1`, authenticated with a [workspace API key](/docs/get-started/authentication) sent as `Authorization: Bearer <key>`, and reaches only that key's workspace. A `GET` reads. A `POST` adds a counterparty or an invoice, with a key that has [write access](/docs/get-started/authentication#scopes), and answers `201` with the record, shaped as its list returns it. A response carries its result in `data`: one object, or for a collection an array, beside `page` with `nextCursor`, `hasMore` and `count` for [paging](/docs/get-started/pagination). A failure answers `{ "error": { "code", "message" } }` with one of the [error codes](/docs/get-started/errors). The same endpoints are published as an [OpenAPI 3.1 document](/api/v1/openapi.json).
