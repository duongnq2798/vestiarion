Every v1 endpoint is a `GET` under `https://www.vestiarion.xyz/api/v1`, authenticated with a [workspace API key](/docs/get-started/authentication) sent as `Authorization: Bearer <key>`, and it reads only that key's workspace. A response carries its result in `data`: one object, or for a collection an array, beside `page` with `nextCursor`, `hasMore` and `count` for [paging](/docs/get-started/pagination). A failure answers `{ "error": { "code", "message" } }` with one of the [error codes](/docs/get-started/errors). The same endpoints are published as an [OpenAPI 3.1 document](/api/v1/openapi.json).
